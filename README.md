# Automatic Secure Network Topology Generator

## Team Name
karnikaperiyasamy

## Problem Statement
Network administrators often need to manually identify connected devices and understand their network structure. This can make network monitoring and management time-consuming. The project aims to provide an automated approach for discovering network devices and generating a clear network topology.

## Solution Overview
Automatic Secure Network Topology Generator is a web-based network management system that automatically discovers devices in a network and generates a secure network topology. It helps users identify network devices, understand their connections, monitor network information, and analyze security-related information through a centralized interface.

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Java, Spring Boot
- Database: PostgreSQL
- ORM: Spring Data JPA
- Build Tool: Maven
- Version Control: Git and GitHub

## Key Features

- Network Device Discovery
- Device Identification
- Automatic Network Topology Generation
- Network Monitoring
- Security Analysis
- IP Address Management
- Reports
- Audit Logs
- Role-Based Access
