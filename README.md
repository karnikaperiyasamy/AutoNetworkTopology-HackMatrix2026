# Automatic Secure Network Topology Generator

## Team Name
karnikaperiyasamy

## Problem Statement
Design and develop a system that automatically discovers network devices and generates a network topology while providing security-focused network insights.

## Solution Overview
Automatic Secure Network Topology Generator is a network management solution designed to automatically discover devices connected to a network, identify their details, and generate a visual network topology. The system aims to simplify network monitoring and provide security-related insights to help users understand and manage their network infrastructure efficiently.
